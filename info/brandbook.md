## 1. Суть бренда

**Собираю систему «маркетинг → контент → продажи» на ИИ — за тебя, под ключ.**
Не курс и не «научу», а «уже сделала себе, соберу такое же тебе».

**Для кого:** эксперты разных ниш (психологи, наставники, коучи), которые выгорели
на ручном контенте и хотят, чтобы это работало без них.

**Кто автор:** специалист по автоматизации контента, вайб-кодингу и нейросетям.
НЕ психолог, НЕ представитель ниши аудитории. Визуал и тексты держат эту роль:
она — тот, кто строит систему, а не «эксперт из ниши клиента».

**Ощущение бренда:** спокойная сила практика. Тёпло, ясно, на «ты», без пафоса,
без канцелярита, без гуру-вещания.

## 4. Типографика

Пара: **Piazzolla** (заголовки, editorial-характер) + **Onest** (текст).
Оба лежат в проекте локально, кириллица есть. Системный sans (`-apple-system`) —
допустимый fallback для веба (так набран сайт).

### Piazzolla — заголовки
- **Роль:** заголовки, крупные хуки, обложки каруселей, титры. Даёт «журнальный»,
  человечный тон — не корпоративный.
- **Начертания:** Regular 400, Medium 500, **Bold 700**; **Italic 500** — для акцентной
  строки/цитаты (есть отдельный файл `Piazzolla-500i`).
- **Кегли-ориентиры (карусель 1080×1350):** обложка-хук 72–96 px, заголовок слайда 48–60 px.
- **Межстрочный:** плотный, 1.05–1.15. Крупный заголовок дышит сам, не разгонять.

### Onest — текст
- **Роль:** основной текст, буллеты, подписи, интерфейсные подписи, тело PDF.
- **Начертания:** Regular 400, Medium 500, SemiBold 600 (для микро-акцентов внутри абзаца).
- **Кегли-ориентиры (карусель):** тело 30–38 px, подпись/сноска 22–26 px.
- **Межстрочный:** 1.35–1.5 для читаемости в ленте.

**Правила пары:**
- Заголовок — Piazzolla, тело — Onest. Не наоборот.
- Не больше двух гарнитур в макете. Marck Script / Unbounded / Comfortaa из папки
  шрифтов — **не** фирменные, в брендовых макетах не использовать.
- Капс — только для коротких плашек/меток, не для абзацев.

## 5. Визуальный стиль контента

Общее правило для всех форматов: **текст не выходит за поля.** Всё важное — внутри
безопасной зоны, с запасом. Никаких обрезанных букв у края.

### Рилсы (вертикаль 1080×1920)
- **Капс-плашки — тил `#0a7089`** (белый текст поверх). Раньше был жёлтый — заменён на тил,
  жёлтый в брендовых рилсах больше не используем.
- **Safe-поля ≥ 40 px** со всех сторон; ключевой текст держать выше нижних 15% (там
  сядут элементы интерфейса платформы).
- Фон-контраст `#0e1116` для тёмных кадров; субтитры — Onest, крупно, высокий контраст.
- Финальный CTA-кадр: тёмный фон `#0e1116` + тил-акцент + кодовое слово/действие.

### Карусели (1080×1350, editorial)
- Тёплый айвори фон `#faf6ef`, заголовки Piazzolla, тело Onest.
- Тил как акцент: номер слайда, подчёркивание ключевого слова, кнопка-стрелка «дальше».
- Один смысл — один слайд. Воздух важнее плотности. Не забивать поле под край.

### Ковры / обложки
- Piazzolla крупно + один тил-акцент. Минимализм: имя, тема, ничего лишнего.
- Тёплый фон или тёмный контраст — но не смешивать три фона в одном ковре.

### Лид-магниты и гайды (PDF)
- Айвори фон `#faf6ef`, тил-заголовки, тело Onest.
- Поля страницы щедрые; таблицы/врезки на тил-фоне `#eef8f9`.
- Единый колонтитул с именем **Евгения Скакунова** / доменом — скромно, приглушённым `#6f7d80`.

## 6. Голос — коротко

Тёплый, ясный, на «ты». Короткие предложения (12–15 слов, одна мысль — одно
предложение). **Без тире**, без вступлений, без канцелярита. Всегда конкретные цифры.
Позиция: «я уже сделала себе, соберу такое же тебе» — не гуру, не мотиватор.

Полный эталон и правила синтаксиса — **`templates/voice-profile.md`** (здесь не дублируем).

## 7. Чеклист «мой это стиль или нет»

1. Главный акцент — тил `#0a7089`? (не жёлтый, не коралл как №1)
2. Фон — тёплый айвори `#faf6ef` или тёмный `#0e1116`, а не случайный цвет?
3. Заголовок — Piazzolla, тело — Onest? Максимум две гарнитуры?
4. Весь текст внутри полей, у рилса safe-поля ≥ 40 px, ничего не обрезано?
5. Тон на «ты», короткими фразами, без тире и канцелярита?
6. Автор подан как автоматизатор/строитель систем, а не как «эксперт из ниши»?
7. Есть путь к монетизации (кодовое слово / CTA / ссылка), а не просто картинка?

Если хоть один пункт «нет» — это ещё не бренд Евгении. Доводим, потом публикуем.
